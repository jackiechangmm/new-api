# 学习使命

我有编程经验，但对本项目的 Go、Gin、GORM、React 和 TanStack Query 技术栈不熟悉。我希望从用户打开 Playground 开始，理解模型调用、路由、渠道选择、预扣费、结算、退款和日志的关键路径与节点，最终能够在这个项目中进行可靠的 vibe coding：能定位入口、追踪状态、判断改动边界，并用最小验证确认行为。

## 学习成果

- 能从 Playground 前端请求定位到 Go 后端入口。
- 能解释用户态 Playground 为什么不使用 API Token，却仍然复用统一 Relay。
- 能画出一次流式聊天请求的计费生命周期。
- 能根据需求找到适合修改的文件，并识别需要补的验证。
