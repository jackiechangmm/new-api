# 领域文档

工程技能在探索代码库时，应按以下规则读取领域文档。

## 探索前读取

- 仓库根目录的 `CONTEXT.md`。
- `docs/adr/` 中与当前工作区域相关的 ADR。

若这些文件或目录不存在，静默继续；不要因缺失而提示或提前创建。只有在确实需要确定领域术语或记录架构决策时，才由相关技能创建。

## 文件结构

本仓库使用单上下文布局：

```text
/
├── CONTEXT.md
├── docs/adr/
└── ...
```

## 使用术语表词汇

在 Issue 标题、重构建议、假设和测试名称中，使用 `CONTEXT.md` 定义的领域术语，避免使用术语表明确排除的同义词。

如果需要的概念尚未定义，应重新确认项目是否已有对应术语；确有缺口时，记录给领域建模工作处理。

## 标记 ADR 冲突

输出内容与既有 ADR 冲突时，必须明确指出冲突及其重新讨论的理由，不能静默覆盖既有决策。
