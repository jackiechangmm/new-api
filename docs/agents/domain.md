# 领域文档

工程技能在探索代码库时按以下规则使用领域文档。

## 探索前读取

- 根目录的 `CONTEXT.md`；或
- 根目录的 `CONTEXT-MAP.md`（存在时），并读取其指向的相关 `CONTEXT.md`；
- 与当前工作区域相关的 `docs/adr/` 中 ADR。

上述文件不存在时静默继续，不提示缺失，也不主动创建。仅在术语或架构决策实际需要澄清时，由领域建模技能按需创建。

## 文档布局

本仓库使用单上下文布局：

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

## 术语与 ADR

输出中的领域概念应使用 `CONTEXT.md` 定义的术语。若与既有 ADR 冲突，应显式指出冲突，而非静默覆盖。
