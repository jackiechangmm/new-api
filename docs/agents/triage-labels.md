# 分诊标签

技能使用五种规范分诊角色。此文件将这些角色映射到本仓库 Issue 跟踪器实际使用的标签。

| 规范角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 Issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由 Agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提及某个规范角色时，使用表中对应的本仓库标签。
